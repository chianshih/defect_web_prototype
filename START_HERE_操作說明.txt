施工缺失管理網頁啟動方法 (Windows)
1. 在 ZIP 檔案上按右鍵 > 全部解壓縮；請勿在 ZIP 內雙擊啟動。
2. 解壓縮後進入資料夾，雙擊 START_HERE_WINDOWS.bat。
3. 第一次需要網路安裝套件。黑色視窗請保持開啟。
4. 在瀏覽器開啟 http://127.0.0.1:5000
5. 若失敗，請拍下黑色視窗的完整錯誤訊息；安裝失敗可附上 setup_log.txt。

如果找不到 Python，按 Win+R，輸入 cmd，接著輸入：
py --version
或
python --version
若兩者均無法顯示 Python 版本，請重新確認 Python 是否加入 PATH。

讓同辦公室的人一起使用（選用）：
1. 用記事本打開 .env，加入一行 HOST=0.0.0.0 後存檔，重新啟動。
2. 黑色視窗會列出可分享的網址（例如 http://192.168.1.23:5000），傳給同事即可。
3. Windows 防火牆跳出詢問時，只勾「私人網路」並按允許。
4. IP 可能會變動，建議請資訊人員設定 DHCP 保留（固定 IP）或內部 DNS 名稱。

登入：開啟網頁後先從選單選自己的名字（不用密碼），之後上傳與修改會記錄是誰做的。
第一次使用請由第一個人輸入名字建立；名單中沒有自己的同事，可選「名單中沒有我」自行輸入全名加入，或由管理員在「後台管理」新增。
管理員設定與維護（備份、權限、常見問題）請看 Admin_Manual.md。
管理員功能：在 .env 加入 ADMIN_PASSWORD=自訂密碼，登入時勾選「管理員」。
注意：選名字沒有密碼，別人可以選你的名字；這只用於留下紀錄，不是資安防護。

請勿把含有真實 API 金鑰的 .env 檔案分享給其他人。
